# Air8000

本仓库基于 Air 系列模组/引擎（例如 Air8xxx）开发。在开始开发或升级固件前，请先学习简短刷机指南（基于 OpenLuat / Luatools） ， 重要链接如下：

- Luatools 使用文档（强烈建议阅读）：https://docs.openluat.com/common/Luatools/
- Luatools 下载页面（最新安装包）：https://luatos.com/luatools/download/last
- LuatOS 官方文档索引（固件、API 等）：https://wiki.luatos.com/pages/tools.html

前置条件

1. 操作系统：仅支持 Windows 10 及以上（Luatools 不支持 macOS / Linux）。
2. 管理员权限：建议以管理员身份运行安装程序和 Luatools（避免驱动安装被拦截）。
3. USB 线与供电：使用高质量数据线并保证稳定电源。刷写过程中严禁断电或拔线。
4. 驱动程序：根据开发板或模块上的 USB 转串口芯片安装对应驱动（常见有 CP210x / CH340 / FT232 等）。
5. 固件文件：确认使用与模块型号/硬件版本完全匹配的固件文件，必要时校验 MD5/SHA256。
6. 硬件手册：准备好模块/开发板硬件手册，了解进入下载/烧录模式的按键/跳线方法。

快速刷机步骤

1. 下载并安装 Luatools（建议放在浅层目录，如 C:\Luatools）。
2. 连接设备并在设备管理器确认出现对应 COM 端口。 
3. 以管理员打开 Luatools，选择烧录功能，选中设备的 COM 端口并载入固件文件。 
4. 让设备进入刷机/下载模式（参见硬件手册的按键或跳线方法）。 
5. 开始烧录，等待完成并提示成功。刷写期间不要断电或拔线。 

常见问题（简洁排查） 
- 找不到 COM：换数据线、换 USB 接口、安装/更新驱动、尝试另一台电脑。 
- 烧录失败或校验错：确认固件完整、重试进入刷机模式、降低波特率、换线。 
- 中途断电变砖：尝试重新进入下载模式重刷；必要时联系供应商支持。 

注意事项
