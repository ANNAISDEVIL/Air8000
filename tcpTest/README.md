# Air8000 TCP Test

这个示例用于验证 Air8000 模块通过 TCP 连接到远端服务器，并周期性发送数据。

## 功能说明

- Air8000 作为 TCP 客户端连接到指定服务器；
- 连接成功后，每隔一段时间向服务器发送一条字符串；
- 服务器端会打印收到的数据和客户端地址；
- 适合用于测试网络连通性、TCP 传输和远程调试。

## 文件说明

- `main.lua`：Air8000 侧的 TCP 客户端脚本；
- `tcpserver.py`：PC 端的 TCP 服务端脚本。

## 1. 运行服务端（PC）

在电脑上安装 Python 3，然后在当前目录执行：

```bash
python tcpserver.py
```

服务端默认监听：

- 地址：`0.0.0.0`
- 端口：`9000`

启动后会持续等待 Air8000 连接。

## 2. 配置 Air8000 客户端

打开 `main.lua`，修改服务器地址：

```lua
local SERVER_ADDR = "223.112.116.189"
local SERVER_PORT = 9000
```

请将 `SERVER_ADDR` 改为你实际运行 `tcpserver.py` 的电脑 IP 地址。

如果你是在本机测试，可以把它改成：

```lua
local SERVER_ADDR = "127.0.0.1"
```

## 3. 烧录运行

1. 使用 Luatools 将 `main.lua` 烧录到 Air8000；
2. 确保已经勾选“添加默认 lib”；
3. 运行脚本；
4. 观察日志输出和 PC 端服务端打印信息。

## 4. 预期现象

### PC 端

运行 `tcpserver.py` 后，控制台会显示：

- 服务端监听中；
- 有客户端连接时打印客户端地址；
- 收到数据后打印数据内容。

### Air8000 端

脚本会：

- 等待网络就绪；
- 建立 TCP 连接；
- 周期性发送：`Hello Server\r\n`；
- 若发送失败或连接断开，则尝试重连。

## 5. 常见问题

### 连接失败

- 检查 `SERVER_ADDR` 是否填写正确；
- 确认 PC 端防火墙没有阻止 `9000` 端口；
- 确认 Air8000 设备已经连上网络。

### 服务端收不到数据

- 确认 `tcpserver.py` 已经正常运行；
- 确认 `main.lua` 中的端口是 `9000`；
- 确认 Air8000 的网络环境能访问到目标 IP。

## 6. 注意事项

- 该示例为基础 TCP 通信测试，未实现复杂协议；
- 生产环境中建议增加心跳、重连、超时处理和数据校验；
- 如果使用公网 IP，请确认网络环境允许外部连接。
